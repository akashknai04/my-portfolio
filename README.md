- **Cinematic Scroll Video Scrubber**: Custom HTML5 Canvas frame scrubbing on scroll for 60fps responsive playback.

- **Career & Education Timeline**: One-by-one scroll entrance animation with signature maroon aesthetic.
- **Get In Touch**: Contact channel with direct mail, social links, and copy-to-clipboard utilities.

- **Frontend**: HTML5, Canvas API, CSS3, JavaScript (ES6+), Three.js
- **AI/ML Focus**: LLMs, LangGraph, CrewAI, LlamaIndex, PyTorch, Hugging Face, PEFT / LoRA, Vision-Language Models, Edge AI (NVIDIA Jetson)
